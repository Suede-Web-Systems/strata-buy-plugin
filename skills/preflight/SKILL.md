# Preflight

Check any buy file — generated by this plugin, hand-tweaked, or received from elsewhere — against the two things that actually go wrong: **structural rejection** ("Invalid Proposal XML file. Import stopped.") and **silent spot loss** (Strata drops spots on non-air days with no error).

## Steps

1. Run both gates:

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/validate_proposal.py" "<buy.xml>"
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/simulate_import.py" "<buy.xml>"
   ```

   (`python3 -m pip install lxml --break-system-packages` if lxml is missing; bare `pip` is often not on PATH.)

2. **Report plainly.**
   - Validator FAIL → the file will likely be rejected outright by Strata. `ERROR (confirmed)` lines are tied to documented Strata rejections or silent drops — report each with its line number. The most common causes and fixes are in `${CLAUDE_PLUGIN_ROOT}/reference/TROUBLESHOOTING.md`.
   - Simulator FAIL → the import will *appear* to succeed but come up short. Report exactly which spots would be dropped and why (the simulator lists them: station, program, date, and the line's actual air days).
   - **WARN lines never disappear into a PASS.** Surface every WARN to the user verbatim, even when both gates pass. WARNs mark deviations from Strata's own output whose import impact is unconfirmed — for a file generated by this plugin they are usually noise, but for a hand-tweaked or externally-received file recommend investigating them before the file is sent.
   - Both PASS → give the user the reconciliation table (intended spots and dollars) and state: "After import, the Strata scheduler should show exactly these totals."

3. **Never soften a FAIL.** A file that fails preflight must not be sent or imported, even if the user is in a hurry — a silently short buy costs more to unwind than a delay.

## Next steps — recommend explicitly

- **On PASS:** "Zip the file before emailing it (bare XML corrupts in transit). After import, compare Strata's totals to the reconciliation table above. Match = done."
- **On FAIL (invalid spots):** "The buy plan needs to be corrected — rerun `/strata-buy:build-buy`, which only places spots on valid inventory." For hand-tweaked files, point to the specific spots to move or remove.
- **On totals mismatch after a real import** (user reports Strata shows fewer spots/dollars than the table): open `${CLAUDE_PLUGIN_ROOT}/reference/TROUBLESHOOTING.md` → "Import succeeded but totals are short."
